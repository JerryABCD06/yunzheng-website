No Uninstall Icon

我不需要卸载图标 A tiny Windows utility for the Start menu.

让开始菜单里不想看到的卸载项，安静地消失。 Make the Start menu shortcuts you don't want to see quietly disappear.

不删除任何文件，也不改卸载流程。它只把选中的开始菜单快捷方式设为隐藏，让列表清爽一点。 Nothing is deleted, and uninstall flows are left alone. It simply hides the Start menu shortcuts you choose.

02 / The problem

卸载项，不应该一直住在开始菜单里。 Uninstall shortcuts shouldn't live in your Start menu forever.

No Uninstall Icon 扫描开始菜单，把所有看起来像卸载项的快捷方式集中到一组。勾选即隐藏，取消即恢复；开始菜单还是那个开始菜单，只是少了几行不想看到的东西。

No Uninstall Icon scans the Start menu, groups every shortcut that looks like an uninstall entry, and gives each one a checkbox. Check to hide, uncheck to restore. The Start menu stays the same — just a little less crowded.

04 / How it works

隐藏，但不动原来的东西。 Hide it. Don't touch anything else.

它只改一个属性：快捷方式的隐藏位。文件还在原处，卸载项也没有被删除。

It changes one attribute: the shortcut's hidden bit. The file stays where it is, and the uninstall entry is not deleted.

工具会记住每个快捷方式最初的属性。取消勾选时，恢复的是原先的状态，而不是把所有隐藏标记都清掉。

The original state of every shortcut is remembered. Unchecking restores that state instead of blindly clearing every hidden flag.

  • 01

    三种状态

    未隐藏、被其它方式隐藏、由本工具管理。界面上分得清，恢复时也不会弄乱。

  • 02

    登录时重新应用

    可选计划任务，每次登录重新应用你的列表；也可以持续监视开始菜单的变化。

  • 03

    键盘完整可用

    方向键、空格、Enter、右键菜单键都已接好。不用为了一个复选框去摸鼠标。

  • 01

    Three states

    Not hidden, hidden by something else, or managed here. The list tells them apart, and restoring doesn't make a mess.

  • 02

    Reapply at sign-in

    An optional scheduled task reapplies your list at sign-in — or keeps watching the Start menu for changes.

  • 03

    Keyboard-friendly

    Arrow keys, Space, Enter and the context-menu key are all wired up. You never need to reach for the mouse.

06 / Native by default

原生 C++，和 Windows 长在一起。 Native C++, at home on Windows.

只用 C++20 和 Windows SDK 写成：没有 .NET，没有 Electron，也没有第三方库。窗口用 Direct2D / DirectWrite 绘制，落在 DirectComposition 表面上；系统提供 Mica 时，它就是一张 Mica 窗口。

Built with C++20 and the Windows SDK only. No .NET, no Electron, no third-party libraries. The window is drawn with Direct2D and DirectWrite on DirectComposition, and uses Mica when Windows offers it.

可执行文件是自包含的，不需要额外安装运行时。支持 64 位 Windows 10（1809 及以后）和 Windows 11。

The executable is self-contained and needs no runtime install. It supports 64-bit Windows 10 (1809 and later) and Windows 11.
