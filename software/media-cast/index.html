媒体投屏 Media Cast

Media Cast 媒体投屏

手机投过来，电脑这边播放。 Send it from your phone. Play it on your PC.

Windows 上的 DLNA / UPnP AV 投送接收器。用手机里熟悉的投送入口，把媒体送到电脑上播放。 A DLNA / UPnP AV receiver for Windows. Use the cast button you already know, and play the media on your PC.

02 / Casting

投屏，本来就应该只是按一下。 Casting should be one button, not a setup project.

Media Cast 接收 DLNA / UPnP AV 投送。手机从相册或支持投送的应用里选择这台电脑，剩下的交给它。

Media Cast receives DLNA / UPnP AV casts. Pick this PC from the gallery or the cast menu you already use on your phone, and leave the rest to the receiver.

04 / The chain

一个窗口，背后是一条完整的播放链路。 One window, a complete playback path.

投送协议、播放内核和桌面界面各做各的事。接收使用 DLNA / UPnP AV，播放交给 libmpv，画面通过 render API 合成进 QML 界面。

The protocol, playback engine and desktop UI each do their job. Casts arrive over DLNA / UPnP AV, libmpv handles playback, and the video is composed into the QML interface through its render API.

关掉窗口，接收还在托盘里；需要让手机暂时搜不到这台电脑时，可以暂停接收投送。

Close the window and receiving continues in the tray. When you want your phone to stop seeing the PC for a while, pause receiving.

  • 01

    接收

    DLNA / UPnP AV 投送。用手机里已经有的投送入口，不必在手机端再装一套配套应用。

  • 02

    播放

    libmpv 负责播放，画面直接合成进 QML 界面。播放体验和界面不是两套东西。

  • 03

    常驻

    关闭主窗口后仍可从托盘接收；暂停接收则会让手机暂时发现不了这台电脑。

  • 01

    Receive

    DLNA / UPnP AV casts, from the cast entry your phone already has. No extra companion app on the phone.

  • 02

    Play

    libmpv handles playback, and the video is composed straight into the QML interface. Playback and UI are one surface.

  • 03

    Stay resident

    Closing the main window leaves the receiver in the tray. Pause receiving to hide the PC from your phone temporarily.

06 / The desktop part

它看起来像 Windows 的一部分。 It looks like it belongs on Windows.

界面使用 Qt 6 + QML 的 FluentUI 风格，跟随系统的深浅色和语言。原生托盘、系统媒体控件和按需出现的窗口，都是桌面端的一部分。

The interface is built with Qt 6 and QML in a FluentUI style, following the system's light/dark theme and language. Native tray integration, system media controls and a window that appears when needed are all part of the desktop experience.

Media Cast 仍在早期开发：目前没有预编译版本，需要从源码构建。仓库里有协议、架构与构建文档。

Media Cast is still in early development: there are no prebuilt releases yet, and it has to be built from source. The repository has the protocol, architecture and build docs.
